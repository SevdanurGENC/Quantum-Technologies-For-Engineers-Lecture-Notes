# Quantum-Technologies-For-Engineers

This repository was created for students in the Software Engineering Department at Osh State University and contains materials from the event titled “Quantum Technologies for Engineers: From Programming to Machine Learning”.

Bu repo, Oş Devlet Üniversitesi - Yazılım mühendisliği bölümü öğrencileri için oluşturulmuş olup, içeriğinde "Mühendisler için Kuantum Teknolojileri : Programlamadan Makine Öğrenmesine" isimli etkinliğin dökümanları yer almaktadır.
